Day 8: Create a Chatbot

This page explains how the AI career coach on this site works and how it was built, from the browser to the AI and back. You can follow the same steps to build your own.

On this page: Big picture Diagram Request walkthrough Build steps Safety Try it Limits and next steps

The big picture

A chatbot here is three parts working together:

1. The page

HTML, CSS and JavaScript in the visitor's browser. It shows the chat and sends each question to our own server.

2. The Worker

A small program on Cloudflare (src/worker.js). It checks the question, adds instructions, and calls the AI with a secret key.

3. The AI model

Claude, run by Anthropic. It reads the conversation and writes the answer.

Golden rule: the browser never talks to the AI directly. If it did, the secret API key would have to be inside the web page, and anyone could copy it and spend your money. The Worker sits in the middle and keeps the key hidden.

What happens when you press Send

  1. The page sends the question. ask.js posts JSON like {"question": "...", "history": [...]} to /api/ask on the same site. history holds the last few messages so follow-ups make sense.
  2. The Worker checks it. It must be valid JSON, a string, not empty and at most 600 characters. The history is trimmed to 6 messages of at most 1500 characters each and tidied so roles alternate user, assistant, user.
  3. The Worker adds instructions. A system prompt tells Claude to act as a short, practical career coach and to politely decline unrelated requests.
  4. The Worker calls Claude. It sends the messages to https://api.anthropic.com/v1/messages with the secret key in a header, the model name from wrangler.jsonc and a cap of 450 tokens.
  5. Claude answers. The Worker pulls the text out of the response and returns {"answer": "..."}. If anything fails, visitors see a friendly message, never raw error details.
  6. The page shows it. markdown.js turns **bold** and bullet lists into real page elements, using only safe DOM calls, never innerHTML.

How it was built, step by step

1

Start from a plain site

A public GitHub repo with public/index.html, style.css and script.js, deployed as a Cloudflare Worker on jayaram.preparingforinterviews.com. No framework and no build step.

2

Create an API key

In the Anthropic Console: add billing credit, set a monthly spend limit, then API Keys → Create Key. Copy it once. It starts with sk-ant-.

3

Store the key as a secret

Never put it in the repo or the page. From a terminal:

npx wrangler secret put ANTHROPIC_API_KEY

Paste the key when asked. It is stored encrypted on Cloudflare and only the Worker can read it.

4

Add a Worker in front of the site

Point wrangler.jsonc at the Worker and keep serving the static files:

{
  "name": "jayaram-app",
  "main": "src/worker.js",
  "assets": {
    "directory": "./public",
    "binding": "ASSETS",
    "run_worker_first": ["/api/*"]
  },
  "vars": { "CLAUDE_MODEL": "claude-haiku-5-5" }
}

run_worker_first sends only /api/* requests to our code. Everything else is served straight from public/.

5

Write the Worker

The heart of it is one fetch call. This is a simplified version of src/worker.js:

const upstream = await fetch("https://api.anthropic.com/v1/messages", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    "x-api-key": env.ANTHROPIC_API_KEY,      // the secret
    "anthropic-version": "2023-06-01"
  },
  body: JSON.stringify({
    model: env.CLAUDE_MODEL,
    max_tokens: 450,
    system: SYSTEM_PROMPT,
    messages: [...history, { role: "user", content: question }]
  })
});
const result = await upstream.json();
const answer = result.content.filter(b => b.type === "text")
                             .map(b => b.text).join("\n");
return Response.json({ answer });
6

Build the chat page

ask.html has the message list, a text box and example question buttons. ask.js sends the question with fetch("/api/ask"), shows "Thinking...", then adds the reply. Enter sends, Shift+Enter makes a new line.

7

Make replies look right

Claude writes in markdown. markdown.js converts bold, italics, headings and lists to page elements by creating them one by one, so a reply can never inject code into the page.

8

Test before going live

The Worker was tested with a fake Anthropic server for: no key, bad input, too long, wrong method, upstream errors and follow-up history. The page scripts were tested against a stand-in page. Then a real question was sent to the live site.

9

Push to GitHub, go live

Committing and pushing to master deploys automatically, usually in under a minute.

git add -A
git commit -m "Add AI chat"
git push

Safety and cost controls

  • Secret key on the server. It is a Cloudflare secret, not in GitHub and not in any file the browser downloads.
  • Spend limit. A monthly limit on the key in the Anthropic Console caps the worst case. This is the control that really matters.
  • Small answers. 450 output tokens and a cheap, fast model keep each question to a fraction of a cent.
  • Input limits. 600 characters per question, and only the last 6 messages of history are sent.
  • On-topic prompt. The system prompt keeps Claude on careers and interviews and tells it to ignore instructions hidden inside a question.
  • No raw errors. Failures log only a status code and show visitors a generic message.
  • Safe display. Replies are drawn as text nodes, so HTML in an answer is shown as text and never runs.
  • Privacy. Conversations are held in the browser only and are not saved by the site. The page warns users not to enter personal details.

Try it

Ask the chatbot you just read about

Open the AI career coach and try: "How do I explain a gap in my resume?" or a follow-up like "Can you make that shorter?"

Honest limits and next steps

  • The rate limit is only a speed bump. Its counters live in each Worker copy's memory, and Cloudflare runs many copies. In a live test, 10 quick requests from one address all succeeded when the limit was 8. A stronger version would use Cloudflare's rate-limiting rules or a Durable Object.
  • The API key expires. The current key expires on Nov 8, 2026. Create a new one and run the wrangler secret put command again.
  • AI can be wrong. Treat answers as guidance and double-check anything important.
  • Ideas to extend it: stream the answer word by word, add a bot-check such as Cloudflare Turnstile, let users save a conversation, or add a mock-interview mode where the bot asks the questions.
